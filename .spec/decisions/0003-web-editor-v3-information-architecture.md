# 0003 · 网页编辑器 v3 采用三栏 + 底部抽屉信息架构，检查器只读且默认收起

- 日期:2026-09-03
- 状态:生效

## 背景

v1（`editor/`）功能链路已跑通，但界面是把所有面板堆在表格下面的 POC：表格不足主区一半高度，主要动作藏在页面中部，冲突处理靠 `window.prompt`。设计师交来的 v3 方案比较了候选 A（三栏 + 底部抽屉，5 实体）与候选 B（两栏 + 右侧多功能面板，4 实体），并附可点原型（`editor/docs/prototype/`）。Owner 的原则是「如无必要勿增实体」，同时补丁 / 冲突需要整屏宽度，检查器与补丁预览需要同时可见。本会话复核时另发现：1280×720 下检查器常驻 260px 会把表格区压到 820px，放不下设计自定的列宽总和（约 1010px），与「面板只在有内容时占空间」的硬要求矛盾。

## 决策

- 布局取 **A**：顶栏 42px、左栏表列表 200px（可折叠 44px）、中央表格、右侧检查器 260px、底部抽屉（收起 30px 页签条 / 展开 240px）、状态条 24px。实体 5 个：顶栏、表列表、表格区、检查器、抽屉。
- **检查器只读 + 动作**（四态四键、还原、删除行 / 撤销删除），不做可编辑值；改值一律格内。
- **检查器默认收起**；选中单元格或点击列头时展开，快捷键或顶栏开关收起，开合状态记 `localStorage`。展开时允许表格横向滚动，不挤压列宽。
- 列头两行（名字 + 必填 / 只读；类型 + 可见性）。
- 导出升格为顶栏主按钮（浅绿描边，次于「提交补丁」）。
- 表末保留 3 个空行 + 工具栏「新增行」；首个空行显示占位文案；空行不预渲染下拉。
- 引入命令面板（`Ctrl+K`）作为切表与动作全键盘化的入口。
- 原型同时以在线页面与仓内静态 HTML（`editor/docs/prototype/index.html`）保存。

## 后果

- 比候选 B 多一个实体（抽屉），换来补丁 / 冲突卡整屏宽与检查器并存。
- 检查器默认收起意味着 J1「看懂每列含义」多一次点击（点列头）；接受。
- 命令面板是新组件，需要自写（不引 UI 库）。
- 五个实体的宽高预算写入 `.spec/knowledge/features/web-editor-ux.md` §2.1，实现卡以 Playwright 量高度验收。
